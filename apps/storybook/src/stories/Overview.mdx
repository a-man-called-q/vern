# Vern UI

Shared shadcn components and design tokens used by Vern's TanStack Start apps.
Use the theme toolbar to preview components in light and dark mode.

Components live in `packages/ui`; add new shadcn components from a generated
app so the CLI routes shared primitives into that package.
